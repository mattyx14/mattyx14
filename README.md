<h2>🌟 OTX Server 2 — Mi proyecto y su ideal</h2>

<p align="justify">
OTX Server 2 es mi proyecto favorito y el lugar donde más he aprendido. Aquí descubrí cómo funciona un servidor por dentro, cómo se organiza un proyecto grande y cómo se construye algo que realmente corre y responde. Es mi espacio de práctica: pruebo, rompo, arreglo, mejoro y vuelvo a intentar. Cada cambio es una pequeña victoria y una nueva lección.
</p>

<p align="center">
<a href="https://github.com/mattyx14/otxserver/tree/otxserv2"><img alt="OTX Server" src="https://raw.githubusercontent.com/mattyx14/otxserver/main/cmake/otxserver.ico" width="120"></a>
</p>

<p align="justify">
El ideal detrás de OTX Server es muy sencillo: <strong>aprender, mejorar y compartir</strong>. No busca ser el servidor más avanzado del mundo; busca ser un lugar donde cualquiera pueda entender cómo funciona un servidor y cómo se puede mejorar poco a poco, sin complicarse la vida.
</p>

<ul align="justify">
<li>Aprender sin presión</li>
<li>Mejorar paso a paso</li>
<li>Código fácil de explorar</li>
<li>Un proyecto que crece contigo</li>
<li>Un espacio para practicar y divertirse</li>
</ul>

<p align="justify">
Para mí, OTX Server es más que un servidor: es el proyecto que me ha ayudado a crecer como desarrollador amateur. Es mi forma de demostrar que con paciencia, curiosidad y ganas, cualquiera puede crear algo que funcione y que inspire a seguir aprendiendo.
</p>
